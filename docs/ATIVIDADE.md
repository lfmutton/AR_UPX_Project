# Atividade — Primeira evolucao do WL01

## Objetivo

Demonstrar que a equipe compreendeu o reconhecimento de imagem e consegue adaptar o template a uma necessidade propria.

## Entrega minima

1. Executar em dispositivo fisico.
2. Reconhecer o marcador de exemplo.
3. Substituir a imagem alvo.
4. Substituir o cubo por outro conteudo.
5. Implementar uma interacao.
6. Documentar as alteracoes no README.

## Evidencia

Video curto demonstrando:

- busca pelo target;
- reconhecimento;
- estabilidade do conteudo registrado;
- interacao.
